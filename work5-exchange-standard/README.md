# work5: 公開台帳データを国総研データ交換標準(素案)へ変換してみる

半田市の公開下水道データ(shapefile)を、国総研「地震対応における下水道管路
データ交換標準仕様書(素案)」(令和 8 年 3 月)の下水道管路パッケージに変換し、
**どこが機械的に埋まり、どこに人の判断が要り、どこに情報の行き場が無いか**を
差分レポートとして出力するデモです。

変換の完成度ではなく、**変換して初めて見える素案と現実の台帳のギャップ**が成果物です。
機械的に決められない箇所は黙って推測せず、すべて判断ログに記録します。

## 使い方

```bash
python convert_to_exchange.py
```

## 出力(output/)

| ファイル | 内容 |
|---|---|
| `handa_exchange_draft.gpkg` | 交換標準形式の GeoPackage。レイヤ名・項目名は素案の応用スキーマの日本語名 |
| `gap_analysis.md` | 地物ごとの充足率/埋められない素案属性/行き場のない台帳属性 |
| `conversion_log.md` | 人の判断で割り当てた項目の全記録(15 件) |
| `quality_violations.csv` | 必須違反・異常値(8 区分) |

## 主な発見(詳細は各レポート)

- **充足率**: 管きょ 24 属性中 7(29%)、マンホール 19 属性中 8(42%)、
  公共ます 2/2、取付け管は素案の定義どおり形状のみ。
- **「排水区域名称・処理区域名称はどちらか必須」が満たせない**: 管きょは両方とも
  台帳に無く全 21,223 本が該当。マンホールも 84.9% が両方空。
- **施設番号(必須[1])の一意性が崩れている**: 人孔キーは欠損 1,726・重複 2,507。
- **台帳語彙とコード語彙の軸が違う**: 人孔種別「塩ビマンホール」(材質) 4,458 基は
  寸法系のコード(Y号〜7号)に載らない。「シールド」(工法) はセグメント材質コードを
  選べない。塩ビ管は薄肉(VU)/厚肉(VP)を台帳が区別しない。
- **素案側に受け皿が無い台帳情報**: 地盤高(絶対標高)、人孔内径の実測値、
  マンホールの施工年度、推進工法のサフィックス、資産番号など。
- **座標系**: 素案指定の日本測地系 2024 は pyproj 3.7.2(EPSG DB v11.022)に
  未登録で、JGD2011 地理座標系(EPSG:6668)までしか機械変換できない。
- **セル内の単位語**: 竣工年度の台帳値は「2015年」という文字列で、Integer に
  入れるには単位語の除去が要る。
