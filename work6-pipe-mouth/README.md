# work6-pipe-mouth — 管口部に絞った点検は、どこまで絞り込めるのか

国総研が第 7 回「下水道管路マネジメントのための技術基準等検討会」(令和 8 年 8 月 20 日)の
資料 3-2 で公表した、管口部(マンホールから 5m 以内)への異状の集中を、
実際の台帳のスパン延長分布に当てはめて「重点化の効き方」を試算するスクリプトです。

```bash
python work6-pipe-mouth/pipe_mouth_focus.py
```

出力(`output/`):

- `mouth_focus_by_band.csv` — 延長帯別の、管口部の延長割合と異状の想定捕捉率
- `span_length.csv` — スパンごとの延長と管口部比率

## 前提と限界

- 国総研の発生密度(管口部 34.6〜34.8 件/m、5〜10m 帯 14.8〜22.0 件/m、
  中央部(資料の「管口以外」・平均 52m)7.9 件/m)は
  **「優先実施箇所以外の緊急度Ⅰ要対策延長・令和 7 年 10 月末時点」の 743 スパン**が母集団で、
  健全な管を含む一般母集団の発生率ではありません。
- したがって本スクリプトが出すのは**異状件数の予測ではなく、絞り込みの効き方の比率**です。
- 「管口以外」を一律 7.9 件/m とすると 5〜10m 帯を過小評価するため、資料の 3 区分どおりに
  3 層で計算しています(2 層に潰すと短いスパンで捕捉率が上振れします)。
- スパン延長はジオメトリ長で、台帳上の管路延長とは一致しない場合があります。

データ出典: 半田市「水道管路等データ」(CC BY 4.0)を加工して作成
