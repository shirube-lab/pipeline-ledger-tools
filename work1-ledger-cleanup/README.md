# 台帳レイヤ品質検査ツール(work1-ledger-cleanup)

管路台帳 GIS のエクスポートデータ(SonicWeb 系)を対象に、納品検査・受入検査で
行う品質チェックを自動化する 2 つのツールです。

出典: 検査対象データは半田市「水道管路等データ」(CC-BY 4.0)。
`s2a_field_mapping.csv`・`qa_report.xlsx` は同データを加工した成果物です。

## parse_s2a_fields.py — 属性辞書の自動抽出

SonicWeb 系エクスポートの shp は属性列が `SAFIELD000` のような無機質な名前に
なりますが、各レイヤに同梱される S2AConfig 形式の XML に実属性名(日本語
タイトル付き)が定義されています。全レイヤの XML をパースして
「SAFIELD → 実属性名」の対応表(`s2a_field_mapping.csv`)を生成します。

## ledger_qa.py — 台帳品質の一括検査

主要 8 レイヤ(上水: 管路・給水管・弁栓・消火栓/下水: 管渠・マンホール・
取付管・桝)に対して以下を検査し、Excel レポート(`qa_report.xlsx`)を
出力します。

- ファイル: 座標系定義(.prj)の欠落、属性定義 XML の有無
- ジオメトリ: 空ジオメトリ、延長ほぼゼロの線、ID 重複
- 属性: 年度・口径・土被りの欠損率、範囲外値、表示様式の混在

### 検査閾値の考え方

閾値はコード冒頭に根拠コメント付きの定数として集約しています。
実務的なポイントは「機械的な範囲外 = エラー」としないことです:

- 口径 0 は「未入力プレースホルダ」として範囲外と区別(実データで 2,000 件超)
- 上限超過は「大型構造物の実在可能性あり・現地資料と照合」の要確認扱い
- 下限未満(0 以外)のみ入力疑義の NG
- 土被りは 0〜15m を許容(それ以上の深埋設は通常なく、負値・桁違いを検出)
- 年度判定は暦年基準(年度=4 月始まりとの差は運用で吸収)

## 実行

```bash
python parse_s2a_fields.py
python ledger_qa.py
```
