# output/ の成果物について

本フォルダの全ファイルは、半田市「水道管路等データ」(CC-BY 4.0)を加工して
作成した**手法デモの試算結果**です。

- **半田市の実際の管路状態の評価・点検計画・更新計画を示すものではありません。**
  評価パラメータ(管種係数・耐用年数の扱い等)は仮定値です。
- `priority_result.gpkg` / `priority_top300.csv` の `ml_pred_urgent` 列は
  **合成の緊急度ラベル**(緊急度Ⅱ以上相当か否か、架空)で学習したデモ値で
  あり、実測に基づく予測ではありません。
- 再利用時は CC-BY 4.0 に基づき「出典: 半田市『水道管路等データ』(CC-BY 4.0)を
  加工して作成」の表記が必要です。

| ファイル | 内容 |
|---|---|
| priority_map.html | 優先度別色分けマップ(免責バナー・出典表記入り) |
| priority_result.gpkg | 全管渠の評価結果(QGIS 用) |
| priority_top300.csv | リスクスコア上位 300 本(冒頭に出典・注記コメント行) |
| future_wave.png | 経年管渠の将来推移(無対策仮定の試算) |
| age_profile.png | 管齢構成(管種別・延長ベース) |
| crs_check_map.html | 座標系検証マップ |
| env_stats.csv | 微地形区分別の管渠サマリ(J-SHIS 250m メッシュ結合) |
