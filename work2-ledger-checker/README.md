# 管路台帳 突合チェックツール(ledger-checker)

GIS の管路台帳(GeoJSON)と現地調査結果(CSV)を突合し、差分・不一致・
データ妥当性エラーを検出して Excel 調書として自動出力するツールです。

上下水道の台帳整備実務で発生する「台帳と現況の突合 → 指摘一覧の調書化」を
自動化することを想定しています。**データはすべて合成(架空)です。**
実在の自治体・事業体のデータは一切使用しておらず、座標もランダム生成の
架空配置で実在の管路位置とは無関係です。

## 検出できる項目

| カテゴリ | 内容 |
|---|---|
| ID 差分 | 台帳のみに存在(調査で未確認)/ 調査のみに存在(台帳に未登録) |
| 属性不一致 | 布設年度・管種・口径が台帳と調査で食い違うレコード |
| 妥当性エラー | 未来の布設年度、規格外の口径、延長 0 以下、管種の表記不正、ID 重複 |

出力される `check_report.xlsx` は「サマリ / ID差分 / 属性不一致 / 妥当性エラー」
の 4 シート構成で、ヘッダー装飾・列幅調整・ウィンドウ枠固定済みの
「そのまま提出できる調書」を意図しています。

## 使い方

```bash
# 1. サンプルデータの生成(合成データ。不具合を意図的に注入)
python generate_sample_data.py

# 2. 突合チェックの実行
python ledger_checker.py --ledger ledger.geojson --survey survey.csv --out check_report.xlsx
```

必要パッケージ: geopandas / pandas / openpyxl

## 設計メモ

- 台帳側は GeoJSON(geopandas で読み込み)。実務のシェープファイルにも
  そのまま対応できます(`gpd.read_file` は SHP も読める)。
- チェック項目は関数単位で分離しており、事業体ごとのルール(管種コード体系、
  口径規格など)の追加が容易です。
- 必須項目の未入力(NaN)は独立の指摘として先に検出し、範囲チェックは
  入力済みの行のみを対象にします(未入力と範囲外の混同を防ぐため)。
- 属性突合は、数値列は数値として(型や欠損による float 化で「1988.0」vs
  「1988」が偽陽性にならないように)、文字列列は前後空白を除去して比較します。
- 「布設年度が未来」の判定は暦年基準です(年度=4 月始まりとの差は運用で吸収)。
- サンプルデータには検出対象の不具合 14 件を注入しており、全件検出できる
  ことを確認済みです。
