# 変換ギャップ分析 — 半田市データ → 交換標準(素案)

変換先の空間参照系について: 素案は「日本測地系2024における緯度経度座標系」を指定する(印刷 p.68)。水平座標の数値は JGD2011 から引き継がれる(測地成果2024 は成果の名称変更で、緯度経度の値は変わらない)ため座標値の変換は不要だが、CRS を「JGD2024」と**名乗る**ための EPSG コードは素案公表(2026 年 3 月)の翌月にあたる 2026 年 4 月(EPSG Dataset v12.055)にようやく登録された。本変換に使った pyproj 3.7.2(同梱 EPSG データベース v11.022)ではまだ参照できないため、JGD2011 地理座標系(EPSG:6668)で出力した(値は同一・ラベルが旧称)。
