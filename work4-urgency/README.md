# work4: 緊急度判定支援ツール(TV カメラ調査結果 → 緊急度Ⅰ/Ⅱ/Ⅲ)

TV カメラ詳細調査の結果(項目別の不良ランク)から、下水道管渠の**緊急度
(Ⅰ/Ⅱ/Ⅲ)**をスパン単位で自動判定し、判定根拠付きのレポート(CSV /
Excel)と地図(HTML)を出力するツールです。

## 大事な用語の区別

- **点検優先度スクリーニング(調査前)** … どこから調査するかの絞り込み。
  → work3 が担当
- **緊急度判定(調査後の診断)** … 調査で見つかった不良の程度から、対策を
  実施すべき時期を判定すること。**本ツールはこちら専用**です。

本デモは「work3 のスクリーニング上位スパンを調査した」という設定で、
半田市オープンデータの管路位置に**合成の調査結果**を重ねています。
**調査データ(不良の記録)はすべて架空**で、実際の管路状態の評価では
ありません。

## 判定ロジックの根拠(すべて無料公開の国資料)

国土交通省「**下水道長寿命化支援制度に関する手引き(案)平成 21 年度版**」
(表 2.3〜2.9)に示された判定例に準拠しています。数値は後継の H25 手引き
(案)本編・参考資料 3 と照合済みです。出典の一覧はレポートの
「判定基準と出典」シートおよび `criteria/default_h21.json` を参照。

- 手引き(案)H21: https://www.mlit.go.jp/common/000044766.pdf
- 手引き(案)H25 本編: https://www.mlit.go.jp/common/001012691.pdf
- 同 参考資料 3(計算例): https://www.mlit.go.jp/common/001012696.pdf

**「準拠」の正確な意味**: 国の資料が示すのは一貫して「参考(例)・(案)」
です。正式な判定基準の本家は日本下水道協会「下水道維持管理指針」(有料)
であり、自治体が独自基準を定めている場合もあります(例: 広島市・横浜市は
公開マニュアルでクラック幅等の閾値が国の例と異なる)。そのため本ツールは
判定基準をコードに埋め込まず、**JSON プロファイル**(`criteria/`)として
外部化しています。自治体基準を使う場合はプロファイルを差し替えてください。

## 判定の流れ(2 段階集約)

```
管1本ごとの評価 (a/b/c)                スパン全体の評価 (A/B/C)
  破損・クラック・継手ズレ・浸入水・       ①腐食  ②上下方向のたるみ
  取付管突出し・油脂・樹木根・モルタル
        │ 不良発生率で集約
        ▼
  ③発生率ランク A/B/C ──────┐
     A: a≧20% or a+b≧40%    │  3項目のランクを数えて判定
     B: a,bあり or a+b+c≧60% ▼
     C: cのみ<60%          緊急度Ⅰ: Aが2項目以上
                           緊急度Ⅱ: Aが1項目 or Bが2項目以上
                           緊急度Ⅲ: Aなしで Bが1項目 or Cのみ
```

特例(手引き(案)表 2.7 備考):
- **破損・継手ズレの a ランクが 1 箇所でもあれば、発生率によらずランク A**
  (道路陥没等の社会的影響を考慮)
- 同一箇所の複数不良は最上位ランクのみカウント

実装上の解釈(手引きに明示のない部分): 発生率の「本数」は管 1 本を最悪
ランクで 1 回だけ数える方式としています。重み付け(手引きは「重みを付けて
算出すると良い」とのみ記載で例示なし)は未実装です。

## 使い方

```
python generate_survey_data.py   # 合成調査データ生成(work3 の出力が必要)
python judge_urgency.py          # 判定 → output/span_urgency.csv + urgency_report.xlsx
python make_urgency_map.py       # 地図 → output/urgency_map.html
python test_judge_urgency.py     # ユニットテスト(手引きの計算例を含む 18 件)
```

入力は実務の調査様式に寄せた 2 ファイル構成です:

- `span_master.csv` — スパン諸元(span_id, 上下流人孔, 管種, 管径, 管本数…)
- `defect_records.csv` — 不良明細(span_id, 管 No, 距離, 項目, ランク)。
  スパン評価項目(腐食・たるみ)はランク A/B/C、管 1 本評価項目は a/b/c

出力の `span_urgency.csv` には**判定根拠列**があり、「どのルールが発動して
その緊急度になったか」を 1 行の文章で追えます(例: 「破損a(管No.4, 8.0m)
→ 特例により発生率ランクA(備考②) / 腐食=A / ランクA×2 → 緊急度Ⅰ」)。

## v1 の範囲と限界

- 対象管種は**鉄筋コンクリート管等・陶管**のみ(手引き(案)表 2.3 の対象)。
  硬質塩化ビニル管は対象外です — 塩ビ管の判定基準として無料で読める一次
  資料は国総研資料第 878 号(研究提案の「案」)のみで、正式基準は有料指針
  側のため、v1 では実装しない判断をしました。
- 上下方向のたるみの基準は内径 3,000mm 以下が対象です。
- 調査データは合成です。実データ適用時は、点検員間のばらつき・偽陰性など
  調査データ自体の品質が最大の論点になります。
- 2025 年 1 月の道路陥没事故を受けて国の技術基準類は見直しが進行中です。
  実務適用の際は最新の基準・自治体の定めを必ず確認してください。
