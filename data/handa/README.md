  https://www.city.handa.lg.jp/opendata/1005557/1005561/1010384.html
- 取得日: 2026-08-03(ページ更新日: 令和 8 年 4 月 1 日、データは 2025-04-23 出力)
- ライセンス: **CC-BY 4.0 国際**。本データを使った成果物には必ず
  「出典: 半田市『水道管路等データ』(CC-BY 4.0)」の出典表記を入れること。
- 市の注記: 位置や属性に誤差が含まれ正確性は保証されない。

## 展開手順

リポジトリには配布元の zip(suidou.zip / gesui_usui.zip / gesui_osui.zip)のみを
同梱しています。クローン後に一度だけ以下を実行してください(標準ライブラリのみ):

```bash
python setup_data.py
```

## 構成(SonicWeb 系 WebGIS のエクスポート形式)

- `suidou/` 上水道: 22001 管路 / 22006 管路区切 / 22011 管路注記 /
  22061 給水管 / 22101 弁栓 / 22116 消火栓
- `gesui_osui/` 下水道(汚水): 24001 マンホール / 24021 管渠 / 24041 桝 /
  24051 取付管 / 24103 副管 ほか注記・シンボル類
- `gesui_usui/` 下水道(雨水): 同系レイヤ構成
- 各レイヤ zip 内にシェープファイル一式。属性エンコーディングは CP932。

## 属性定義(確定 — 各レイヤの S2AConfig XML から抽出)

各レイヤフォルダの `<コード>.xml`(S2AConfig)に SAFIELD → 実属性名の定義が
日本語タイトル付きで完備されている。全レイヤの対応表は
`work1-ledger-cleanup/s2a_field_mapping.csv` に抽出済み(抽出ツール:
`parse_s2a_fields.py`)。主要レイヤの要点:

| レイヤ | 件数 | 主属性(XML 確定) |
|---|---|---|
| 汚水/雨水: 管渠 24021 | 21,223(汚) | **施工年度**(欠損11.5%)/ 管種名称 / 管径1(mm) / 上流土被り(m) / 下流土被り(m) |
| 汚水/雨水: マンホール 24001 | 20,689(汚) | 人孔キー / 下水道区分・種別 / 処理分区・排水区 / 人孔種別・内径1・2 / **人孔深(m)・地盤高(m)** / 舗装種別 / **施工年度・布設年度** / 資産番号 |
| 汚水/雨水: 取付管 24051・桝 24041 | 39,443 / 39,391 | 管種名称 / 取付管管径(mm) / 本管までの距離(m) / 上流人孔からの距離(m) |
| 上水: 管路 22001 | 26,045 | 管種 / 口径(mm) / 土被り(m)。**年度属性なし** |
| 上水: 給水管 22061 | 45,740 | メータ口径(mm) / 給水管種 / 給水口径(mm) |
| 上水: 弁栓 22101・消火栓 22116 | 10,211 / 1,343 | 46 項目: 弁種類 / 材質 / 口径 / 開閉状態 / 配水系統・ブロック / 実測圧・設定圧 / **布設・設置年度** / **修繕経歴・内容・業者×5** / 固定資産番号 ほか |

- 1 つの shp に複数の SASTYLEID(表示様式)が混在(例: 24021 に 241xx 系と
  243xx 系)。分析前に SASTYLEID でのクレンジング・分類が必要
  → これ自体が作品 1(台帳データ整備)の実演材料になる。
- 分析メモ: 劣化予測(作品 3)の主対象は汚水管渠(施工年度×管種×管径)。
  弁栓・消火栓は修繕経歴まで持つため、点設備の維持管理デモにも拡張可能。

## 座標系(要検証)

.prj 欠落のため CRS 不明。座標範囲(x: -26.6km〜-17.6km, y: -125.5km〜-117.4km)
から**平面直角座標系 第 VII 系と推定**(半田市の位置と整合)。JGD2011 なら
EPSG:6675。QGIS で背景地図と重ねて位置整合を検証してから使用すること。
